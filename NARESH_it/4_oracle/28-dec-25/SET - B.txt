Task: Develop a Software System for Education Loan Schemes
You are tasked with creating a software system for a government agency responsible for administering education loan schemes across different states. 
Each state has unique policies for education loans, including different loan amounts provided by the central government. 
The system should dynamically determine and display the education loan scheme for a given state. 
For states that do not yet offer loan facilities, the system will display an appropriate message.

System Requirements
1. Create the CentralGovernment Interface
Purpose: This interface defines the contract for all states participating in the central government's education loan scheme.
Components:
A final double amt = 20000.0, representing the base loan amount provided by the central government.
An abstract method educationLoanScheme() that each state will implement to define its specific loan scheme.
A static method message() that prints a welcome message for the central government education loan scheme.

2. Create Concrete State Classes

Maharashtra Class
Implements the CentralGovernment interface.
Provides an additional loan amount of 10000.0 on top of the base amount.
Implements the educationLoanScheme() method to display the scheme details.

Telangana Class
Implements the CentralGovernment interface.
Provides an additional loan amount of 15000.0 on top of the base amount.
Implements the educationLoanScheme() method to display the scheme details.

NonState Class
Implements the CentralGovernment interface.
Represents states that do not currently provide education loan facilities.
Implements the educationLoanScheme() method to display the message: "Yet, Your State is not providing any loan facility."

3. Create the StateFactory Class
Purpose: This class is responsible for generating instances of the state classes dynamically based on the state name provided.
Components:
A static factory method getStateInstance(String stateName) that: Accepts the name of the state as input.
Returns an instance of the corresponding state class (Maharashtra, Telangana, or NonState).
Uses conditional logic (equalsIgnoreCase()) to determine the correct state class.

4. Create the ELC Test Class
Purpose: Serves as the entry point of the program to test the functionality.
Steps:
Call the static message() method from the CentralGovernment interface to display the welcome message.
Prompt the user to input the name of the state.
Use the StateFactory class to generate the appropriate state instance.
Call the educationLoanScheme() method on the generated instance to display the loan scheme or a fallback message for non-participating states.
