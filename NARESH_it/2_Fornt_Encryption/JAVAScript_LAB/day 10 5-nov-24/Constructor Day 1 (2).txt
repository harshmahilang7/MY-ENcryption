Q 1) 
Create a JavaScript Program to Manage a Movie Collection
Create a constructor function named Movie that takes in the properties title, director, year, and genre.
Implement a function addMovie() that:
	Reads movie details (title, director, year, genre) from input fields.
	Creates a new Movie object.
	Adds this object to a movies array.
Create a function displayMovies() that:
	Iterates over the movies array.
	Displays each movie’s details on the webpage
